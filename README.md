## Описание

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием Bootstrap.

## Используемый фреймворк

Bootstrap.

## Способ подключения

Bootstrap подключён локально из папки `vendor/bootstrap/`.


## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── css/
│   └── custom.css
├── images/
├── vendor/
│   └── bootstrap/
│       ├── css/
│       │   └── bootstrap.min.css
│       └── js/
│           └── bootstrap.bundle.min.js
└── README.md
```

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница товара;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили проекта;
- `images/` — изображения проекта;
- `README.md` — описание проекта.
- `images/` — изображения товаров и баннера.
- `vendor/bootstrap/` — локально установленный bootstrap.

## Описание самостоятельных доработок

- **Локальное подключение Bootstrap без CDN:** Фреймворк подключен локально из папки `vendor/bootstrap/`.
- **Более сложная структура каталога:** Реализована двухколоночная сетка с сайдбаром для фильтрации товаров, хлебными крошками и блоком сортировки.
- **Дополнительные Bootstrap-компоненты / Использование дополнительных компонентов:** 
  - `accordion` — блок частых вопросов (FAQ) на странице каталога;
  - `carousel` — адаптивный слайдер с кастомным форматированием на главной странице;
  - `tabs` — интерактивные переключаемые вкладки для раздела «Преимущества проекта»;
  - `toast` — динамическое всплывающее уведомление при отправке формы заявки на `order.html`;
  - `pagination` — постраничная навигация по товарам в каталоге.
- **Более подробный README.md:** Подробно описана структура проекта, приведен полный список используемых элементов UI и указан перечень всех выполненных доработок.
- **Публикация проекта через GitHub Pages:** Проект успешно развернут и доступен по ссылке на GitHub Pages.
